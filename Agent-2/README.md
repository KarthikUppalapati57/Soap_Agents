# Agent 2 - SOAP Note Quality Evaluator

## Overview
Agent 2 evaluates the SOAP notes generated by Agent 1 using 
OpenAI HealthBench metrics.

## Model Used
- llama3.2 via Ollama

## Input
- Agent 1 one-shot results (50 samples)
- File: `v2/v1_results.json`

## Evaluation Metrics (HealthBench)
| Metric | Score |
|---|---|
| Accuracy | 0.912 |
| Completeness | 0.870 |
| Context Awareness | 0.813 |
| Instruction Following | 0.835 |
| Communication Quality | 0.633 |
| **Overall Score** | **0.838** |

## Key Findings

Agent 1 (one-shot) is good at:
- ✅ Getting medical facts right
- ✅ Capturing patient details
- ✅ Following SOAP format

Agent 1 needs improvement in:
- ⚠️ Writing quality and clarity
